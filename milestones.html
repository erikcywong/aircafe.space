Two Curves Decide Whether This Works

两条曲线决定这件事成不成

The cycle curve is the product claim. The cost curve is the investment claim. Neither is a forecast — the first is measured, the second is a target we are willing to be held to.

周期曲线是产品主张，成本曲线是投资主张。两者都不是预测——第一条是实测，第二条是我们愿意被拿来问责的目标。

The 18-Month Milestone Ladder18个月里程碑阶梯

Each rung below is a gate, not a description of activity. Capital is released only when the rung above it has been certified — which means a missed milestone is visible at the next release point rather than at the end of the round.

下面每一级都是闸门，而不是对活动的描述。只有在上一级被确认之后，资金才会释放——这意味着一个未达成的里程碑会在下一个释放点就被看见，而不是等到本轮结束。

Milestone里程碑 Window时间窗 Certification test确认标准 Tranche释放比例
